| 项 | 本轮行为 | 主要位置 |
|---|---|---|
| 1 PPTX | 按演示文稿引用顺序读取标题、正文、表格文字；切片保留幻灯片编号。旧 PPT 提示转换，纯图片/空白文稿失败，混合文稿逐页提示 OCR；限制解压体积和页数。 | 后端 `app/agent/knowledge.py`、前端资料库 |
| 2 PDF 与标签 | 过滤重复页边文字、页码、编著/题型说明；识别中文章节及课程术语，保留页码、章节、原文切片及知识点依据。可修改、确认、去重、重新提取既有正文；清除没有测评证据的废弃文档标签及其派生候选，保留已完成任务。 | 知识库 API、KnowledgeBase 页面 |
| 3 聊天事实 | 无当前图片和完整题干的指代请求明确要求补充，不调用识图或编造诊断；模型提示明确附件事实边界。历史通过请求上下文按账号和聊天会话隔离，待确认档案操作也按会话隔离。 | chat_llm、chat API |
| 4 学习意图 | 只有明确的学习安排/复习/练习等行动请求才新建目标，功能介绍等咨询不启动。卡片保留目标、下一步和测评摘要，协作交接和调度轨迹默认折叠。 | chat API、ChatMain |
| 5 等待体验 | 出题等待显示实际经过秒数和生成说明；可退出，失败可重试；离开或账号变化时丢弃过期响应并清理计时器。无伪造百分比。 | ExercisePractice |
| 6 解析来源 | 资料明确标注基础解析。交卷结果增加 pending/completed/unconfigured/basic/failed 真实状态；基础解析可先看，后台 AI 完成后条件回填。页面每3秒查询，最多20次，并提供手动刷新入口；查询不重复评分。 | review_jobs、exercises API、ExercisePractice |
| 7 搭子偏好 | 可保存主攻课程、学习目标和空闲时间；聊天、资料展示和匹配共同使用服务端画像。去除按知识点数量猜主攻课的逻辑；空时间稳定性0分，互补只使用有测评证据且置信度有效的掌握度，空基础资料不加分；校验时间格式。 | profile/preferences、partner_match、PartnerMatch 页面 |
| 8 信息收起 | 计划调整、计划依据、暂未安排、候选池及画像变化历史默认收起，显示数量和摘要；计划版本、优先级和重排原因使用中文及知识点名称。 | StudyPlan、PlanDiffCard、StudyTags、assessment_replan |
| 9 本次计划 | 导入知识点只更新候选池。用户先选课程再确认时长，按薄弱程度安排最多3项任务，剩余知识点留在候选池，不生成30分钟积压。首次读取历史自动积压计划时转换候选并保留完成记录、版本及历史；切换课程保留已完成任务。 | profile_merge、plans API、StudyPlan |
| 10 登录记忆 | 最近账号回填；“记住账号”和“保持登录”分开选择。关闭保持登录时凭据仅在内存，不持久保存；退出清除凭据且调用服务端退出。未增加密码保存。 | AuthStore、Login |
| 11 我的与作业 | “管理”跳账号页；首页和账号详情页的待处理数字均打开作业清单。支持全部/待处理/临近/已完成筛选、详情与标记完成；数字排除已完成作业，沿用当前账号的本地持久化完成记录。 | Index、Account、CourseImport、AppState |
