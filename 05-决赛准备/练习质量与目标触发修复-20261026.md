# 练习质量与目标触发修复（2026-10-26）

## 原因与修改
1. 选题提示使用语音共用提示栏，切换功能不清理。现在功能选择统一通过chooseIntent清理提示；错题诊断保留选图入口，不再显示常驻选题提示；普通功能切换隐藏旧目标摘要。
2. 资料题只检查引用出处，没有教育质量门槛。现在通用题与资料题共用校验，拒绝“掌握程度要求”和掌握/熟悉/了解等级选项；资料生成提示要求考概念、推导、算法执行或应用。只含考纲等级的材料不作为学科正文。生成、缓存复用、旧题交卷三处检查；旧无效题返回409，不新增掌握度或测评。已完成的历史记录不删除。材料不足明确要求补充定义/原理/例题，通用练习需用户主动切换。
3. 待处理作业标签改为“待处理作业 ›”，保留统一统计卡尺寸和点击进入待处理筛选的行为。
4. “我要更新学习画像”被宽泛的“我要…学习”规则误判。现在显式排除画像更新、查看、否定学习等输入；普通问答不附带既有learningContext。当前上下文可保留供历史选择，但页面不因刷新或普通回复常驻展示。确认题目建目标、明确开始练习、从历史选目标时显示；收起仍可展开；历史保留。
5. 目标卡标题改为“练习与测评”，用“练习内容”和具体下一步说明状态，不默认显示原始长输入、学习秘书和交接术语；进度详情按需展开。
6. 补防旧数据：v2文档里仍含“掌握”等无效标签也会在读取时清理；修订快照保留，未测评文档标签退出画像和待办，完成记录保留。已测评历史不删，但无效标签不再供目标选点或聊天薄弱点上下文使用。旧画像更新误建目标不作为当前目标，可从历史查看和结束。
