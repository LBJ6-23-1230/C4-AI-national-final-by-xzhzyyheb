## 启动和安装

在仓库根目录的 PowerShell 中运行：

```powershell
.\start-backend.ps1 -Check
.\start-backend.ps1
```

已有后端窗口时无需再启动第二个进程。当前 Debug mode 为 off，修改 Python 代码不会自动重载；如果后端在本轮修复前启动，请先在原窗口按 Ctrl+C，再重新运行启动命令。保持后端窗口运行。不要为测试覆盖已有 .env 或删除账号数据库。注册与账号隔离测试使用两个新测试账号，先选手机号和密码方式；新账号初始画像为空是设计行为。

安装测试包并启动应用（DevEco 默认安装路径如下，其他机器按安装位置替换）：

```powershell
$hdc = 'D:/develop/DevEco Studio/sdk/default/openharmony/toolchains/hdc.exe'
& $hdc -t 127.0.0.1:5555 install -r 'deliverables/user-test-20261025/知学Mate-user-test-20261025-signed.hap'
& $hdc -t 127.0.0.1:5555 shell aa start -a EntryAbility -b com.zhixue.mate
```

覆盖安装出现签名不兼容时记录错误，不直接卸载，以免丢失本地数据。真机换成实际设备标识，且必须属于当前调试签名允许的设备。

应用内进入「我的 → 关于 → 连续点击版本号 5 次 → 接口环境」。联机测试关闭 Fixture：模拟器后端地址为 `http://10.0.2.2:5000`；真机使用同一网络内开发机的 IPv4 地址。先确认连通性，再开始业务操作。

## 建议执行顺序

| 顺序 | 操作 | 验收重点 |
|---|---|---|
| 1 | 注册账号 A，退出后用手机号和密码重新登录 | 新账号从零开始；勾选记住我后重启能恢复会话，不需要重新注册 |
| 2 | 添加课程/知识点或导入讲义，再查看画像和计划 | 空状态有引导，课程与资料归属正确，新增知识点能够进入计划 |
| 3 | 文本聊天，发送后立刻切页再返回，切换历史会话 | 不永久停在发送中；旧会话响应不进入新会话；后端无 Key 时说明规则回退 |
| 4 | 获取练习、选择答案、交卷；请求中切页再返回 | 交卷只记一次，结果与画像一致；超时重试使用原答案，不产生重复记录 |
| 5 | 同时操作资料库 A/B，切换、搜索、上传、删除 | 旧请求不覆盖当前资料；文档数量正确，删除来源后有明确提示 |
| 6 | 开始专注、暂停、结束、重启应用；断网结束后恢复网络 | 时长和暂停次数正确，草稿可恢复，待同步记录补交且不重复 |
| 7 | 错题练习、计划时间预算调整、继续学习目标 | 错题计数与移除规则正确；画像、计划版本和目标进度一致 |
| 8 | 注册账号 B，反复切换 A/B 与游客身份 | 不串聊天、资料、计划、错题、专注记录；真实搭子邀请需用两个登录账号 |
| 9 | 联机/Fixture 切换、断网恢复、快速返回、连续点击 | 错误提示可理解，能重试；Fixture 不能冒充服务器真实注册与同步 |
| 10 | 锁屏/回前台、横竖屏、长文本、软键盘与通知/语音 | 检查布局、计时连续性、返回位置和权限拒绝后的恢复；这些必须通过实际设备交互确认 |

## 本轮不作为成功验收的能力

生产短信发送和华为可信登录适配尚未接入：测试拒绝/降级提示，不把返回 503 当成新出现的界面故障。开发验证码仅在显式开发配置下可用，不表示真实短信已发送。

真实文本模型、课表图片识别、拍题和语义检索需要独立验证模型服务。未配置或不可用时先测错误提示与回退；离线检查通过不能证明这些模型能力可用。
