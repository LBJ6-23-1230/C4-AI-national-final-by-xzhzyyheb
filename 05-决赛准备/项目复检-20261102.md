## 发现的问题与风险

1. **`tools/start_emulator.ps1` 默认 DevEco 路径错误**：写的是 `D:/develop/DevEco Studio`，本机实际为 `D:/DevEco/DevEco Studio`；不传 `-DevEcoHome` 会直接报缺少 `Emulator.exe`。`tools/sign_hap.ps1` 同样默认错误。建议改默认值。
2. **公开仓库无 signingConfig**：`app/build-profile.json5` 的 `signingConfigs` 为空，hvigor 提示 `No signingConfig found for product default`，产出的是 unsigned HAP；在 DevEco 里点 Run 无法直接安装到模拟器，需要先在 Signing Configs 配置 `E:\zhixue-signing` 的调试证书。现有 11-02 包是已签名产物，可直接 `hdc install`。
3. **HAP versionCode 不递增**：10-30 与 11-02 都是 `1000000`，建议发版时同步递增。
4. **`app/hvigorfile.ts` 引用工程外文件**：`import '../tools/hvigor-resource-compat.cjs'` 位于仓库根 `tools/`。单独拷贝 `app/` 目录会构建失败；若需独立分发 app，应把该文件移入 `app/hvigor/` 并改相对路径。
5. **`.env` 缺失**：大模型与 PostgreSQL 均未配置；新解压环境账号库为空。公开仓库这样是安全的，但现场演示前必须补齐。
6. **控制台中文横幅乱码**（`run.py` 启动 banner）：不影响功能，属于终端编码问题；`check_database.py` 已做 UTF-8 重配置，可作为参考。
7. **`/api/v1/auth/status`、`/api/v1/profile` 返回 404**：这两个路径不在 `openapi.json` 的 81 条契约内，前端也未调用，不属于缺陷。
