# 云端部署与上架交接

本次按《部署服务器+数据库+上架方案》和《postgresql数据库部署方案》修改项目。部署入口是 `server/zhixue-agent-server/deploy/README.md`，配置样例为同目录的 `.env.production.example`、`.env.worker.example` 和 `.env.migration.example`。

## 已落实

- PostgreSQL 仓储、Alembic 结构迁移、连接池、跨进程事务保护及幂等约束。
- 独立持久化 Worker，讲解/资料解析/原文件删除任务支持恢复、心跳、租约令牌及有限重试。
- 云端聊天消息入库、原文件私有存储适配、鉴权下载、文件摘要及解析版本来源。
- JSON/SQLite 导入工具、试运行和逐条核验，已用人工数据完成一次真实备份恢复演练。
- Docker、Gunicorn、HTTPS 网关、健康/就绪探针、发布和逻辑备份脚本、角色授权样例。
- App 开发/演示/生产环境生成工具；生产环境锁定域名，忽略旧的本地地址和 Fixture 设置，关闭调试与游客入口。
- App 展示后台资料处理状态、轮询结果；保留交卷重试时的同一个幂等键；增加登录失效、维护和画像版本冲突提示。
- 经用户明确授权实现云端完整注销清理，并更新界面后果说明和数据流说明。

## App 环境准备

当前源码保持 development，默认 `http://10.0.2.2:5000`，便于继续本机联调。不要把占位域名写进正式包。

```powershell
# 决赛环境：换成真实演示域名。
python tools/prepare_app_environment.py --environment demo --api-url https://demo.your-domain.cn
# 正式环境：必须是实际的公网 HTTPS 域名。
python tools/prepare_app_environment.py --environment production --api-url https://api.your-domain.cn
python tools/prepare_app_environment.py --environment production --api-url https://api.your-domain.cn --check
# 本地开发恢复。
python tools/prepare_app_environment.py --environment development --api-url http://10.0.2.2:5000
```

`tools/build_phase9.ps1 -BuildMode release` 增加生产环境检查，未准备生产环境会拒绝构建；参数 `-DevEcoHome` 指定本机安装位置，`-SdkHome` 可指定已验证 SDK。该脚本生成 HAP 用于验证；最终商店提交仍需要在 DevEco/AGC 使用正式发布签名构建商店要求的 APP 包，并保管原有应用身份与签名。

生产构建不恢复开发版保存的局域网地址，不允许 Fixture，也不能通过“我的”版本连点重新开启调试。环境生成文件不含任何后端或数据库密钥。

## 仍需队伍提供并实测

|项目|需要完成的实际动作|
|---|---|
|云账号/预算/地域|购买或提供 ECS、RDS、私有桶、镜像仓库，确认同地域私网和安全组|
|正式域名和证书|配置 DNS、HTTPS 和数据库 CA，测试公网访问|
|模型/短信|提供服务账号、额度和真实策略；目前短信和可信华为登录接入未完成|
|应用主体/签名|核对包名、应用身份、开发者主体和发布签名，生成发布 APP 包|
|隐私和支持页面|按实际数据流填写主体、联系方式、服务商、保存期限和删除方式，发布可访问网页|
|资质与备案|由主体按实际类别和官方流程核对；域名、应用备案与商店审核分别跟进|
|真机验收|Wi-Fi/移动网络、注册登录、过期会话、上传失败、任务处理中断、注销、重复交卷|
|生产恢复|在云端完成独立实例恢复、OBS 对账和文件恢复、实测 RPO/RTO|

账号、学习画像/计划、练习结果、错题、聊天内容和上传资料均可能在后端保存；模型功能会将必要的问题、文本片段或图片发送给配置的模型服务。隐私页面不能继续宣称“仅上传画像和练习结果”。界面已有事实说明，但尚不能替代含真实主体与联系方式的完整隐私政策。

## 决赛演示建议

使用独立演示库与演示桶，提前固定两组账号、资料和题目。可展示重复交卷只计一次、账号资料隔离、Worker 被强制停止后重启恢复、资料切片与原文件摘要溯源，以及备份恢复报告。备用机仍可运行 SQLite 和离线 Fixture，备用环境数据不会自动同步云端。

生产审核与决赛演示使用不同数据库和账号；不要在审核环境执行演示重置。现有 `hap/` 归档安装包不会因源码修改自动更新，必须以本次构建产物为准。
