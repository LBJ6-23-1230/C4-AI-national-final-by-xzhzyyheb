导入工具会核对远端地址、分支和干净的工作区；排除本地数据库、上传原文件、依赖缓存、私钥、真实 `.env` 文件，移除构建配置中的签名凭据，并检查大文件和常见 API Key 格式。它保留 `.env.*.example`、源码、文档和验收证据。工具不提交、不推送、不修改 `.git`。

远端独有的文件会保留；请在 `git status` / `git diff` 中检查是否需要清理旧文件。导入后目录有修改属于正常现象，工具会拒绝再次覆盖这个有修改的目录。

## 2. 核对后自行提交与推送

```powershell

git diff --cached --stat
git diff --cached --check
if ($LASTEXITCODE -ne 0) { throw '存在空白错误，请先修正。' }

```
