# 拍照批改首轮验收

本轮验证按知识点动态出题、编辑识别稿、评分和错题归档。解答题练习记录单独显示在所属知识点下，用于推荐后续练习。正式掌握度仍按现有有效测评证据计算。

## 准备

1. 在仓库根目录运行 `./start-backend.ps1`，确认后端已配置视觉模型。若已有测试后端在运行，先确认它已更新到本轮代码。
2. 在 DevEco Studio 运行新版应用，或安装 `app/entry/build/default/outputs/default/entry-default-signed.hap`。用测试账号登录，让真机连接到更新后的后端。局域网联调时，手机和电脑连同一个 Wi-Fi，并在「接口环境」填入电脑地址和后端端口。
3. 进入「练习智能体 → 专项练习 → 解答题」。知识点可以手动输入，也可以从学习画像中选择。

## 出题和换题

1. 输入「传输时延」，选「计算题」并点「生成题目」。确认条件、数据和单位足够作答。点击「下一题」，确认仍考查传输时延，题目情境或数据有变化，上一题没有新增练习记录。
2. 点「调整出题条件」，将知识点改为「二叉搜索树的中序遍历」，选择「简答题」。确认生成题需要解释、推导或分析。两种题型在提交前都只展示题面。
3. 另选一道题点「不会做，查看解析」。确认页面显示「已标记不会做」，可看解析和加入错题本。正式掌握度分数没有变化。

## 手写批改

每种题型选定一道生成题，分别写三份作答。看完评分后点「重做本题」上传下一份。至少用一次「拍照」和一次「从相册选择」。

| 用例 | 作答方式 | 检查点 |
| --- | --- | --- |
| 全对 | 写出完整过程，计算题按题干要求写单位和精度 | 10/10，识别稿和原作答一致 |
| 部分正确 | 计算题故意算错最后结果，解答题省去一处关键论证 | 已写对的步骤得分，反馈指出错算或漏写的位置 |
| 修改识别稿 | 上传计算题作答，修改识别稿中的最终数值，再确认评分 | 评分按编辑后的数值核对。原样确认时可直接展示已有评分 |
| 换一种正确解法 | 计算题换一种合理的推导或换算顺序，解答题用等价论证 | 认可正确的等价解法，说明得分依据 |
| 模糊图 | 另拍一张，让关键算式或最后几行完全看不清 | 提示重新拍摄。换清晰照片后可以提交 |

## 通过标准

- 两种题型都能按选定知识点生成，换题成功。出题页、题面和评分页分别有明确的主操作。
- 六份清晰照片的题目和作答对应正确。出现「核对识别结果」时核对或修改文字，再点「确认并查看评分」。评分点合计等于总分，解析与题干数据相符。
- 未满分后点「加入错题本」，确认题目按课程和知识点归类，并可从错题本进入同类解答题。打开知识点目录，核对解答题练习次数和最近参考分。重做同一题只计一道。
- 分开记录出题、识别和改稿后评分耗时。识别从点「识别作答」开始，看到识别稿或补拍提示时停止。
- 返回专项练习完成一轮选择题，确认可以正常交卷并查看解析。

每个用例记一行「题型、知识点、预期分、实际分、识别是否准确、耗时、问题截图」。发现分数偏差时，先根据识别稿区分是读图有误，还是评分点应用有误。
