# “我的”统计数据刷新修复 · 2026-11-04

安装包：[知学Mate-我的统计刷新修复-20261104-signed.hap](知学Mate-我的统计刷新修复-20261104-signed.hap)。仓库 `hap/知学Mate-signed.hap` 已同步更新。

## 修复原因与行为

旧统计卡使用按值传参的 `@Builder`，数字在首次渲染后没有建立更新依赖。账号数据稍后恢复或同步成功，页面仍会保留最初的 0；切换标签重新创建卡片时才可能显示数据。此外，计划异步加载完成时未重新计算任务完成度。

- 统计卡改用 `@Component` 和 `@Prop`，数据变化直接更新已有数字。
- 首次显示先读取当前账号的本机记录，再同步课程、作业和专注历史；读取失败保留已有记录。
- 切换到“我的”、从子页面返回、计划加载和专注状态变化时重新计算统计。
- 专注记录数统计全部已加载记录，避免被“最近 7 条”的列表截断。
- 切换账号或离开页面后，忽略过期的统计刷新回调；真实空账号仍显示 0。

- 同一账号旧包有数据却显示0，新包显示实际统计。记录、标签切换、子页面返回与重启验证通过；账号截图、界面导出及设备原始记录仅保存在本机，不上传GitHub。

本轮只修改前端，无需更新后端。当前包沿用开发接口配置；没有创建、修改或删除账号中的测试记录。模拟器之外的真机尚未验证。包大小和 SHA-256 见 `artifact.json`。
