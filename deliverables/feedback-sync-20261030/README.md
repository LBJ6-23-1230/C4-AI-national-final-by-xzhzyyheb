# 用户反馈修复版

`zhixue-feedback-sync-signed.hap` 为本机签名调试包，支持覆盖安装并保留应用数据。大小和 SHA-256 见 `artifact.json`。

包含今日重点折叠、提醒反馈修复、课程与作业跨设备同步、知识点筛选、练习表现复盘。

两台设备均需更新，连接同一后端并选择同一个账号。旧课程和 DDL 若只保存在原设备，应先在原设备更新并登录上传，再在另一设备同步。

数据库需升级到 `20261030_03`；当前电脑开发库已备份并升级。其他部署环境须通过迁移角色执行 `alembic upgrade head`。

详细行为、验证结果和边界见 [修改验收记录](../../项目文档/用户反馈修改验收记录-20261030.md)。
