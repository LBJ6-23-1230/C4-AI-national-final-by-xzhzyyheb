# 2026-11-02 截图反馈修正版

安装包：`知学Mate-截图反馈修正版-signed.hap`。已保留模拟器原数据覆盖安装。后端须同时使用当前工作区代码；本机后端与 Worker 已加载修改，健康检查通过。

模拟器效果：[首页](效果截图/首页.jpeg)、[任务详情](效果截图/任务详情.jpeg)、[学习页](效果截图/学习页.jpeg)、[知识点筛选](效果截图/知识点筛选.jpeg)。

| 反馈 | 修改及原因 |
|---|---|
| 1. 首页两个入口重复、缺少红字 | 主按钮改为“立即开始”，作业进入对应任务的专注计时，知识点任务进入对应练习；“查看全部待办”仍打开完整列表。首页优先展示任务的标题及截止提醒恢复红字。开始前重新核对当前计划，已移除或已完成的任务不会误启动，已有专注和待结算记录受保护。 |
| 2. 已匹配科目还要求匹配 | 原判断把“没有主题分组”也当成“科目未匹配”。现在只有缺少有效科目才要求匹配；主题可选，已属于数据结构、操作系统等课程的知识点可直接练习。未识别主题不再妨碍使用。 |
| 3. 计划仍出现“待确认科目” | 统一过滤各数据来源中的占位科目，包括已保存计划、课程、作业及知识点候选池；计划、练习、复盘均使用有效课程名称。未知归属内容继续保留，可在知识点列表手动选科目。 |
| 4. 学习页留白 | 内容滚动区改为顶部对齐，收紧顶部间距，常用操作紧接页面说明。知识点列表筛选后只有少量结果时也保持顶部对齐。首页悬浮 AI 按钮上移，避免挡住底部“我的”。 |
| 5. “标记完成”含义 | 原按钮只修改复习清单状态，不能证明已练习或掌握。已移除；提交对应知识点的练习后自动显示“已提交对应练习”，并提供学习报告入口。过去的手动勾选会注明尚无对应提交记录，不伪装成练习证据。此状态不直接提高掌握度。 |
| 6. 查看任务后不知道做什么 | 学习任务入口改为“任务详情”，按所点任务 ID 展示名称、科目、时长、步骤和状态，并说明开始后去哪里；明确区分“开始本项练习/立即开始专注”与“查看整体学习计划”。拆分作业显示各步骤，避免直接启动整个原任务。考试复习入口标为“开始本项复习”。移除该页遮挡底部操作的悬浮按钮。 |

已知科目且缺少主题时，无须重新匹配；只有无法识别科目时才提示手动选择。既有内容和作答记录保留。本轮未替真实账号保存匹配、完成作业或重新生成学习计划；写入与计时路径使用隔离测试数据验证。
