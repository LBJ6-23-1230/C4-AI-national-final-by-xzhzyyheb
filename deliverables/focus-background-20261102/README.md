# 2026-11-02 后台计时与息屏区分

安装包：`知学Mate-后台计时与息屏修正版-signed.hap`。包含上一轮专注暂停、学习数据精简和提醒设置简化。

普通专注在任务开始面板和专注设置页均提供“允许后台计时”开关，新任务默认关闭，选择随本次任务保存，不会自动为之后的新任务开启。

| 操作 | 开关关闭 | 开关开启 |
|---|---|---|
| 手机息屏或锁屏 | 继续计时 | 继续计时 |
| 主动返回或切换其他应用 | 自动暂停，回来点击继续 | 继续计时 |
| 用户主动点击暂停 | 保持暂停 | 保持暂停 |
| 亮屏并解锁回到专注页 | 延续息屏期间的计时 | 继续计时 |
| 解锁后留在桌面或其他应用 | 按切换应用处理，暂停 | 继续计时 |

计时页显示当前后台计时规则，开启时右上角标记“普通 · 后台计时”。严格模式保持不可手动暂停；息屏不再被误记为中断，切换应用仍计中断。

通过系统电源状态及息屏、锁屏、解锁事件区分离开原因，并合并页面隐藏与应用后台的重复回调。事件顺序识别窗口不会额外增加暂停任务的专注时长。账号或当前任务发生变化后，旧回调不会修改新任务。

恢复已有任务时保留后台选择、手动暂停状态和已记录的离开原因。只有明确允许的后台计时或已识别的息屏会继续累计；旧记录缺少这些信息时，普通模式仍按上次保存时长暂停恢复。系统回收进程后通过保存的时间戳还原进度，不依赖后台每秒执行，也不意味着已接通后台推送或到点通知。
