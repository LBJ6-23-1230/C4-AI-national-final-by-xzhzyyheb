# 2026-11-02 专注暂停与提醒设置简化

安装包：`知学Mate-专注暂停与提醒简化版-signed.hap`。

- 普通专注离开页面、返回或切到后台时自动暂停；回来后保持暂停，点击“继续专注”才重新计时。正计时遵循同一规则。首页和专注设置说明恢复后的暂停状态。
- 普通专注冷启动恢复时，只保留上次已保存的专注时长，不补算离开期间；运行时每5秒保存一次进度。异常进程终止可能丢失最后一次保存后最多约5秒的进度。已经由旧版本计入的时长不追溯猜测或改写。
- 保留严格模式不可手动暂停、离开计入中断的规则；返回键需要确认中断。暂停的任务不再被上报为正在专注。
- 删除“我的”页面的“计划时长达成率”及对应汇总计算，保留任务完成度、实际专注分钟、专注记录、连续天数和待处理作业。历史专注与任务完成记录保留。
- “摘要时段”改为“每天提醒开始时间”。9:00、12:00、18:00使用有勾选标记和蓝色背景的按钮；显示正在保存、已保存的具体时间或保存失败，失败保留原设置。说明这是最早安排时间，不保证整点发送。
- “时间预算冲突”改为“学习安排超时提醒”，说明它会在安排用时超过已确认可用时间时提示调整计划。“学习间隔”改为“久未学习提醒”的应用内说明，去掉当前无实际后台通知作用的开关。
- 通知状态改用完整说明：系统通知权限需要用户允许；后台提醒服务未接通时，应用关闭后暂时收不到通知。首页待办仍可查看，提醒偏好可先保存。开启系统权限不会自动配置服务端推送。
