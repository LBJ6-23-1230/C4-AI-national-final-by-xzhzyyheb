## 五处反馈

1. **练习题未加载**：截图对应现场出题未获得可用题目，原实现将模型未配置、鉴权、连接、超时及输出校验失败合并成一句话，无法从该截图追溯唯一原因。现在返回分类原因与可采取的操作，不显示无帮助的“本次等待 2 秒”。按题数提高输出长度预算，减少整批题 JSON 截断风险；不会拿其他知识点题目冒充。本机独立模型样例为“数据结构：哈希表”，一次生成 3 题成功，耗时约 10.44 秒，仅证明本次请求成功。
2. **账号页冗余**：删除账号页重复的“提醒与设备设置”和“当前是独立账号”说明卡片。保留“我的 → 提醒设置”入口。
3. **提醒偏好**：免打扰起止时间改用系统时间选择器，可设置任意时分，支持跨天与单独关闭。已有 23:00—09:00 等设置继续保留。首页学习提醒增加开关，明确说明只在打开首页并展开“今日安排”时显示，不发手机通知；修复旧代码生成了久未学习事件却未展示到首页的问题。后端覆盖旧偏好兼容、分钟边界、关闭、紧急例外与不同账号隔离。
4. **后台通知**：已有客户端 Token 绑定、提醒规则、独立提醒 Worker 与华为发送适配器。本机尚无项目 ID 和 JWT 路径配置，不能真实推送。新页面分别展示服务配置、系统授权与设备连接情况，明确这是开发团队需要开通的服务。尚无 JWT 自动签发/续期器；需要部署轮换机制，并完成真实项目与真机验收。完整步骤见[通知开通步骤](../../server/zhixue-agent-server/deploy/通知开通步骤-20261103.md)。
5. **隐私说明**：重写为“登录与账号、学习记录与 AI 功能、位置与提醒、退出与注销”四组短说明；移除面向开发者的“加盐哈希”“后端”“凭据”等说法。退出与注销的页面说明、确认文案一并改为用户容易理解的表达，保留清除记录及不可撤销的实际后果。
