| 具体行动 | 规则建议使用具体知识点与已有错题，明确作答、核对、记录错误和验证结果。采纳复盘行动后进入统一计划的待安排区，不自动增加时间预算。 |
| 今日与本周计划 | 今日只显示当天可执行任务；本周按用户确认的每日分钟数排期，未填写日期默认为0分钟。按截止日安排，无法容纳的任务保留并解释原因。增加时间前显示确认，完成记录与进行中任务受保护。 |

## 秘书失败的定位证据

找到了北京时间2026年11月2日10时35分59秒的失败记录，其快照含4个已测知识点，与截图时间相符。使用该快照和修改前代码重放真实模型调用，模型正常返回第1至第4项行动，旧代码的允许集合却只包含前3个知识点，复现日志为 `AssertionError check=point_id`，随后回退到规则建议。

另外，旧接口将同日相同快照的规则回退也直接缓存返回，因此模型恢复后再次生成仍可能显示旧建议。原历史记录没有保存细分异常，不能把本次重放当作原请求异常日志；它确认了相同输入下可复现的校验缺陷和缓存问题。

修复后的同一快照真实调用结果为 `source=model`、3项行动、空失败原因，未再触发该校验。复查中出现过一次18秒等待上限超时，因此进一步压缩了模型输出、将上限调整为30秒，并保留明确提示和重试入口。外部模型服务仍可能超时或限流，界面会如实说明。

## 使用与边界

首次使用本周计划时，填写每一天实际可用的分钟数，再生成排期。未确认具体钟点时只给日期与执行任务，不虚构日历时段。较长作业可先按明确产出拆分，再安排到不同日期。

模拟器保留原账号和原有资料。本轮没有自动替用户保存知识点匹配结果、改变真实作业的完成状态或重新安排其现有计划；相应写入与冲突逻辑使用隔离数据验证。手动匹配后，正常返回画像和练习即可读取更新结果。

通知功能尚未完成本轮后台或锁屏送达验收；没有把推送未配置、无权限的状态当作已可用。模型建议来自真实调用或明确标注的基础建议，不将规则回退伪装成模型输出。
