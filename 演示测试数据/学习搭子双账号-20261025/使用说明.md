# 学习搭子双账号测试资料

这两套资料分别用于你已注册的账号 A 和账号 B，不会替你创建账号、设置密码或修改现有账号。

| 设置 | 账号 A | 账号 B |
|---|---|---|
| 建议昵称 | 林知远 | 苏念 |
| 年级 / 专业 | 大二 / 计算机科学与技术 | 大二 / 计算机科学与技术 |
| 学习目标 | 数据结构考试80+ | 数据结构考试80+ |
| 每天空闲时间 | 19:00-21:30 | 19:30-22:00 |

两人有 5 门共同课程，上课时间不同；共同学习时段为 19:30–21:30，共 120 分钟。DDL 每人 6 条，日期从 2026-10-27 到 2026-11-07，均晚于本套资料制作日 2026-10-25。导入器的 DDL 是日期粒度，不包含精确到小时的截止时间。

## 导入步骤

1. 使用联机模式登录账号 A：在课程/课表导入入口选择“账号A-林知远-课表.png”，识别后核对 5 门课程与考试日期并确认。
2. 在作业/DDL 导入入口导入“账号A-林知远-DDL.json”，核对 6 条作业。
3. 切换到账号 B，使用 B 的课表与 DDL 文件执行相同步骤。不要把两套文件一起导入同一个账号。
4. 在账号档案中分别设置上述相同目标和空闲时间，确认同步至后端，再打开搭子匹配。
5. A 发出邀请，切换 B 查看并接受，再回 A 查看联系人。

当前图片识别只提取课程与考试信息，不会自动把周课表空白格转成后端 freeTimeSlots；DDL 文件也不设置空闲时间。空闲时间要通过档案设置或支持更新档案的聊天操作填写，并核对服务端是否实际保存。

图片识别需要真实视觉模型可用。如果识别失败，可导入对应“课程备用.json”验证其他业务；这是绕过视觉识别的备用路径，不代表识图测试通过。课程和 DDL 使用独立 JSON 文件，避免自动类型检测把组合文件只识别为 DDL。

导入课程、设置目标/空闲时间后，应能在真实账号候选中看到另一位同学；具体排名还受其他已有账号、知识点掌握度等因素影响，不保证固定分数或一定排第一。文件不包含或伪造知识点强项。

若文件在电脑上，需先通过模拟器文件管理/上传功能传入模拟器，或在 DevEco/hdc 中传入应用选择器可访问的文件目录；电脑路径不能直接当作模拟器中的文件路径。
