# 大纲推荐验收

使用当前 HAP 和后端。在独立演示账号下创建「计算机数值分析」知识库，避免其他文件干扰题源。

1. 先只上传《期末复习大纲.txt》，等文件显示「处理完成」。进入「智能体 → 练习 → 专项练习」，选「计算机数值分析」，保持「推荐」和「全部主题」，清空搜索。等待显示「已读取复习大纲」。二分法和复化梯形公式带有「大纲重点」及文件名。牛顿法不会因这份大纲被标为重点。
2. 点大纲推荐的「二分法」，确认题源页显示暂无可出题的同课程正文，提供「开始通用练习」。返回即可，无需在这一步出题。
3. 回到同一课程知识库上传《二分法讲义.txt》，等「处理完成」。再次进入专项练习，二分法因有配套正文优先展示。点二分法，确认默认题源为《二分法讲义.txt》，再点「开始资料练习」。
4. 进入作答页后，核对「本轮题源」和题下的「查看原文依据」。原文来自讲义，能找到题目考查的内容。

功能可直接读取已处理的大纲与讲义正文，这套样例无需手动确认知识点。若显示「暂时无法分析大纲」，先检查 App 的接口地址及后端的文本模型配置。
