# 知学 Mate 华为账号登录真机交接

## 接收文件

- 项目源码已整合华为登录与 1.0.6 的知识库和练习功能。测试时使用当前的 App 和后端。
- 使用最新的 [知学Mate-signed.hap](知学Mate-signed.hap)。目标平板需在调试 Profile 的设备列表里。若不在，由应用管理员登记平板 UDID 并用更新的 Profile 重新签包。

## 测试后端配置

在运行知学 Mate 后端的机器上，打开 `server/zhixue-agent-server/.env`，添加下列配置。第二项在华为开发者中心选择 `com.zhixue.mate`，进入「基础信息 → 基本信息 → OAuth 2.0 客户端 ID（凭据）」，点 Client Secret 右侧的复制按钮，直接把完整值填入服务器配置。

```dotenv
HUAWEI_ACCOUNT_CLIENT_ID=6917617022690149565
HUAWEI_ACCOUNT_CLIENT_SECRET=这里替换成开发者中心复制的完整值
```

Client Secret 仅由有权限的同学保存在后端环境中。使用 HTTPS 时，从平板浏览器访问 `https://<实际测试域名>/ready`，应返回 `{"status":"ready"}`，且浏览器接受证书。测试地址应转发全部知学 Mate API。若 Nginx 和 Windows 后端在同一台电脑上，Nginx 的 HTTPS 入口可转发到 `http://127.0.0.1:5000`。云端 Compose 模板的上游是 `api:8000`。

## 平板操作

1. 在平板系统「设置」顶部登录准备测试的华为账号。
2. 安装包含本次登录修复的签名 HAP。需要配置连接时，从华为账号入口下方点「查看连接设置」。
3. USB 联调仅在 development 构建开放。连接数据线并确认电脑的 USB 转发服务已运行，然后选择「使用 USB 联调地址」，地址为 `http://127.0.0.1:5000`。此前误保存的 `https://127.0.0.1:5000` 会在开发版冷启动时修正。使用演示包、发布包或其他网络连接时，使用设备信任的 HTTPS 根地址。
4. 返回登录页，点「使用华为账号登录」。应用先检查后端是否就绪，通过后再打开系统授权。

固定测试域名后，可以在打包前用 `tools/prepare_app_environment.py --environment demo --api-url https://<实际测试域名>` 设置演示包的默认地址。已安装设备上的自定义地址会保留，可在「接口环境」应用正确的 HTTPS 地址或切换回构建默认后端。

## 验收与排查

| 测试 | 预期 |
| --- | --- |
| 第一次使用测试华为账号授权 | 建立知学 Mate 账号并进入首页。新账号从空画像开始 |
| 退出后使用同一华为账号重新登录 | 回到同一知学 Mate 账号 |
| 关闭并重新打开 App | 会话恢复，可以继续访问真实后端 |
| 取消授权或授权码无效、已使用 | 留在登录页，无法获得新会话 |
| 选择手机号密码登录 | 原有登录方式可用 |

如果浏览器打不开 `/ready`，先检查测试后端和 HTTPS 地址。若华为系统授权页报错，记录错误码，核对系统账号、开发者中心的应用和签名。若 App 提示服务暂不可用，检查测试后端的 Client ID、Client Secret 配置和到华为账号服务的网络。反馈时提供设备系统版本、操作步骤和脱敏错误码即可。
