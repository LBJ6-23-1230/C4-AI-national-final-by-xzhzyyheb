# 决赛演示视频 · 录制与交付

现有第三视角真机画面用于开场、拍题和双机操作等镜头。用同一版本的真机录屏展示界面、操作过程和结果。开录前对照第三视角里的按钮、页面和任务名称，补录有差异的镜头。

## 开录前

1. 从 [HAP 目录](../hap/README.md) 确认本次安装包、构建版本和 SHA-256。在录制设备上验证签名包能覆盖安装并打开。两台设备用同一个版本。
2. 在仓库根目录启动 API 和后台作业 Worker。展示系统通知时才加 `-WithReminders`，并确认后端推送配置和设备通知权限。

   ```powershell
   .\start-all.ps1 -Restart
   .\start-all.ps1 -Status
   powershell -ExecutionPolicy Bypass -File .\tools\check_llm_ready.ps1
   ```

   `/ready` 确认数据仓储可用。模型自检分开检查文本、识图和向量模型。用演示文件完成一次资料处理和出题，确认 Worker 实际推进了作业。
3. 在真机打开「我的 → 账号、安全与隐私」，连点版本号五次进入「接口环境」。应用真机可达的后端地址并点「检查连接」。两台真机的后端地址需一致。`http://10.0.2.2:5000` 用于模拟器。
4. 准备独立演示账号、同一门课的讲义和一张清晰题图。按录制日期核对考试与作业截止时间。使用本次实际成绩和计划差异。

## 录制顺序

| 段落 | 应拍到的结果 |
| --- | --- |
| 从课程进入 | 保持同一门课、同一份讲义，展示导入结果和文档处理状态 |
| 专项练习 | 选知识点，核对系统匹配的同课程讲义，再点「开始资料练习」。打开一道题的出处和原文，完成实际作答 |
| 学情与计划 | 展示交卷后的知识点结果。若有重排，拍到调整前后和触发原因 |
| 执行 | 从计划任务进入专注，结算后打开学习记录 |
| 可选的双机片段 | 手机开始共享专注。平板点「在这台设备继续」，拍清剩余时间，最终只新增一条学习记录 |
| 可选的拍题或语音片段 | 拍题先核对题干。语音拍清按住、转写、松开编辑和发送 |

语音、双机接管和系统通知以本次真机验证的镜头为准。若主机或网络切换，重新在两端检查连接。剪辑时隐藏手机号、授权信息和内部服务地址。

课程有复习大纲时，在「专项练习 → 推荐」等待「已读取复习大纲」，再展示知识点卡片的「大纲重点」和文件名。后续镜头展示用来出题的讲义和对应正文。可用[大纲推荐验收样例](../演示测试数据/大纲推荐验收/README.md)分别彩排只有大纲和补充讲义两种情况。

## 视频交付

仓库沿用的命名为 `演示视频+暗影骑士王们.mp4`。导出后与 [答辩文稿](../答辩文稿.md) 对照一次画面、用词和数字。录制前置步骤与镜头顺序以本页为准，其他分镜用于选取旁白和画面。
