## 交付内容和复核命令

ZIP 的顶层目录为 `ZhixueMate`，适配 DevEco 工程路径限制。包内包含签名 HAP、DevEco 工程、后端源码和部署模板、数据库迁移、接口契约、演示样例、启动脚本、本套手册及 Windows x64 Python 3.12 离线依赖。首次使用时按[后端部署](02-后端部署.md)生成评审环境的 `.env` 和演示数据库。

将最终 ZIP 解压到英文短路径，例如 `C:\C4`。进入 `ZhixueMate` 下包含 `app/`、`server/` 和 `hap/` 的项目根目录。先确认未启动后端，再运行：

```powershell
python -B tools/check_runtime_data.py --strict .
python -B tools/diff_contracts.py
Get-FileHash -Algorithm SHA256 -LiteralPath '.\hap\知学Mate-signed.hap'
```

检查运行数据和契约都通过，并对比 `hap/manifest.json` 的哈希。然后按手册从该解压副本安装、启动后端和使用样例。任何未覆盖的设备或外部依赖请记录实测结果。
