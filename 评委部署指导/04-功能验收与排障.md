# 04 功能验收与排障

先按[安装 HAP 与打开工程](01-安装HAP与打开工程.md)启动应用。香港实例的联机验收见[云端评审快速开始](00-云端评审快速开始.md)。以下本机复现步骤使用独立演示后端、测试账号和样例文件。

## 1. 三分钟确认可以演示

1. 核对 `hap/manifest.json` 中的 HAP 版本和校验值。在设备桌面打开「知学 Mate」，确认登录页正常显示。
2. 点「离线演示（无需网络）」，打开首页、练习和计划。使用内置样例完成一次作答，查看作答反馈。记录本次走的是内置离线数据。
3. 在线验收时，先在后端电脑打开 `http://127.0.0.1:5000/ready`。应返回 HTTP 200 和 `{"status":"ready"}`。如果后端部署在其他主机，请使用部署手册给出的地址。
4. 回到 App 的「接口环境」，配置实际根地址，点「检测后端连接」。看到「连接成功：真实后端与数据服务均已就绪」后，使用「跳过登录，在线体验」。有独立演示账号时，用该账号登录验证用户数据的持久化。

## 2. 验证从资料到学习计划的流程

参照 [出题机制与 DDL 导入](06-出题机制与DDL导入.md)，打开 `演示测试数据/指导老师预演-20261028/`，将以下文件放到**设备或模拟器**的下载目录。可用 DevEco Studio 的设备文件管理，或用 `hdc file send` 传到当前设备文件选择器可访问的下载目录。传完先在设备的「文件管理」确认能找到文件。要测试图片选择器，可先将样例图片保存到系统图库。

| 现场步骤 | 文件和预期现象 |
| --- | --- |
| 导入课程 | 从「课程与作业」导入 `02-课程与DDL/01_A_courses.csv`，检查 3 门课程及考试日期，再确认导入。 |
| 导入作业 | 切到作业，导入 `02-课程与DDL/03_A_DDL.csv`，检查 4 条作业及截止日期。样例日期固定在 2026 年。要演示即将截止的排序，可复制文件后将副本中的日期改为相对评审日的未来日期。 |
| 上传讲义 | 在「知识库」中选对应课程，上传 `03-上传讲义/05_binary_tree_notes.txt`，等待处理完成，再打开文件查看原文和可用知识点。 |
| 作答和复盘 | 在「智能体 → 练习 → 专项练习」按同课程选知识点。确认题源后作答，观察本轮题源、判分和反馈。若显示「查看原文依据」，打开原文核对题目依据。 |
| 查看任务和画像 | 提交后查看学习记录、课程画像及计划。可用第二组不同答案或调整时间预算观察变化，按实际页面记录结果。 |

要专门演示「先读大纲、再从讲义出题」，用[大纲推荐验收](../演示测试数据/大纲推荐验收/README.md)中的两个 TXT 文件。只上传大纲时检查「大纲重点」和通用题选项。补充对应讲义后检查资料题和原文依据。文本模型和材料处理能力以本次后端实测为准。

## 3. 按需验收联机能力

| 能力 | 验收方法 |
| --- | --- |
| 持久化与账号隔离 | 在演示账号 A 新建一条带当天时间标记的记录。退出并用 A 再登录，核对同一条记录。用独立账号 B 登录，核对 A 的私人数据未出现在 B 的列表。要确认后端实际使用 PostgreSQL，按数据库手册用独立数据库核对结构和本次新增记录。 |
| 学习搭子 | 准备 A、B 两个真实存在于本次演示后端的账号，分别导入[双账号测试资料](../演示测试数据/学习搭子双账号-20261025/使用说明.md)。设置共同课程、目标及空闲时段。A 发邀请，B 确认接收并接受，再回 A 查看联系人和后续协作。 |
| 模型对话和图片识别 | 检查后端已配置可用的文本和视觉模型。在真实后端中分别发送一条文本和一张清晰的样例题图，核对返回的来源与实际识别内容。视觉模型不可用时，可用课程 CSV 继续验证后续步骤，并记录图片识别未通过。 |
| 华为账号登录 | 在已授权的真机上登录系统华为账号。确认受信的 HTTPS 后端地址可达，OAuth Client ID 与 Secret 已在后端配置，并使用与 AGC 配置匹配的签名 HAP。开发包也可以按前端手册使用 USB 联调。首次授权后核对账号进入成功，再退出并复登核对账号一致。 |
| 双设备接续 | 两台兼容设备先连接同一演示后端。验证同账号数据同步时，两端用同一演示账号，在一端写入后另一端刷新检查。验证学习搭子时使用两个独立账号。依赖系统分布式能力的场景另外检查设备互信、权限和会话状态。 |
| 提醒和服务卡片 | 先检查系统通知权限，再创建一项尚未到期的演示任务，并确认提醒服务的配置。需要 Push 真机到达时，另核对签名、AGC Push、服务账号、设备 token 和 Worker。 |

## 4. 独立复核源码和数据

如已按后端手册安装 Python，在解压后的项目根目录运行以下命令。

```powershell
python -B tools/diff_contracts.py
python -B tools/check_runtime_data.py --strict .
```

第一条应报告 `PASS`，表示 `contracts/` 和 `app/contracts/` 的接口契约一致。第二条用于**刚解压、尚未启动后端**的交付副本，应报告 `PASS`。开始验收后，应用会按配置生成自己的演示运行数据。

## 5. 常见故障怎么定位

| 看到的现象 | 先做什么 |
| --- | --- |
| `hdc list targets` 为空 | 等模拟器进桌面。真机解锁后检查开发者选项、USB 调试、弹出的电脑授权，以及 USB 线能否传数据。确认使用 DevEco SDK 的 HDC。 |
| HAP 安装失败或系统不支持 | 先核对 SHA-256 和目标 API 级别。记录安装错误码。如果提示签名、Profile 或设备未授权，请联系团队签名管理员。 |
| DevEco 打开后提示缺 SDK 或依赖 | 确认选中 `app/` 文件夹，安装 6.1.1（24）SDK，检查 OHPM 下载与代理。签名路径缺失时用团队现成签名 HAP 安装，或配置个人签名重新构建。 |
| 电脑能开 `/ready`，真机连不上 | 检查 App 填的是正确的根地址。Wi-Fi 模式先用真机浏览器访问电脑 WLAN 地址的 `/ready`。检查电脑防火墙、热点和同网隔离。USB 模式检查设备仍出现在 HDC 列表、转发服务仍运行。 |
| `/health` 正常而 `/ready` 返回 503 | 后端进程存活。核对该实例使用的存储类型、数据库连接和结构版本。按数据库手册处理后重查 `/ready`。 |
| App 说后端不可用而浏览器可达 | 检查是否仍在离线 Fixture、地址是否已「应用」、协议是否与实际服务匹配。用 HTTPS 时检查域名与证书链，证书须在设备上受信。 |
| 华为登录授权后回到登录页 | 先单独验证在线访客入口和 `/ready`。再核对设备系统华为账号、后端 OAuth 配置、包名和签名，记录脱敏错误码。 |
| 选不到电脑上的讲义或课表 | 将文件传入设备/模拟器本地下载目录，在系统文件管理里确认它已到达。文档选择器和图库是不同入口。 |
| 资料出题失败或对话标为本地规则 | 先确认讲义「处理完成」、课程匹配，再检查文本模型凭据、模型名称和后端到模型服务的网络。原文依据、离线或规则输出按实际来源记录。 |
| 练习或提交超时 | 先恢复连接，查看记录是否已有结果，再根据页面提示重试。跨设备和长耗时模型场景可分别单独复测。 |

如需反馈，请保留 HAP 版本与校验值、设备型号/API 级别、离线/在线模式、操作步骤、时间及脱敏错误码。涉及存储时一并注明 `/health`、`/ready` 状态与本次使用的数据库类型。截图和日志请遮挡设备标识、账号、密钥与个人学习记录。
