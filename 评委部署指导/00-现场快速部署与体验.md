# 知学 Mate 评委快速开始

> 使用已部署的香港服务时，请按 [云端评审快速开始](00-云端评审快速开始.md) 操作。以下是自行部署的路径。

完整解压 ZIP 到英文短路径，例如 `C:\C4`，进入解压出的 `ZhixueMate` 目录。PowerShell 命令从这个目录运行。现场用一台 Windows x64 电脑、Python 3.12 x64 和 API 24 的 DevEco Studio 模拟器，也可以用签名 Profile 已授权的 HarmonyOS 真机。

## 1. 安装应用，体验离线样例

打开 DevEco Studio 的 Device Manager，启动 API 24 模拟器并等它进入桌面。使用真机时先开启 USB 调试并接受电脑授权。将下方 `$Hdc` 改成实际安装的 DevEco SDK 中 `hdc.exe` 的路径。

```powershell
$Hdc = 'C:\Program Files\Huawei\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe'
$manifest = Get-Content -LiteralPath '.\hap\manifest.json' -Encoding UTF8 | ConvertFrom-Json
$hap = Join-Path '.\hap' $manifest.file
if ((Get-FileHash -LiteralPath $hap -Algorithm SHA256).Hash -ne $manifest.sha256) {
    throw 'HAP 的 SHA-256 与清单不一致，请重新解压。'
}
& $Hdc list targets
& $Hdc shell param get const.ohos.apiversion
& $Hdc install -r $hap
& $Hdc shell aa start -a EntryAbility -b com.zhixue.mate
```

目标应只列出一台，API 级别应至少为 `24`。在登录页点「离线演示（无需网络）」，查看首页、练习和计划，用内置题目完成一次作答。多设备选择、签名报错、DevEco 源码构建及 USB 转发见 [01 安装 HAP 与打开工程](01-安装HAP与打开工程.md)。

## 2. 启动独立演示后端

先确认 `py -3.12 --version` 能显示 Python 3.12。首次启动使用 ZIP 附带的 Windows x64 离线依赖，初始化一份独立的 SQLite 演示库。

```powershell
$backend = '.\server\zhixue-agent-server'
$python = Join-Path $backend '.venv\Scripts\python.exe'
if (-not (Test-Path -LiteralPath $python)) {
    py -3.12 -m venv (Join-Path $backend '.venv')
    if ($LASTEXITCODE -ne 0) { throw '创建 Python 虚拟环境失败。' }
}
& $python -m pip --disable-pip-version-check install --no-index --find-links '.\offline-wheels\windows-py312' -r (Join-Path $backend 'requirements.txt')
if ($LASTEXITCODE -ne 0) { throw '安装依赖失败。请检查 Python 版本、架构和解压目录。' }
& $python -m pip check
if ($LASTEXITCODE -ne 0) { throw '依赖检查失败。' }
$config = Join-Path $backend '.env'
if (-not (Test-Path -LiteralPath $config)) {
    @'
APP_ENV=development
ZHIXUE_DB=sqlite
DEMO_ENABLED=true
ZHIXUE_ENABLE_DEV_TOOLS=0
FILE_STORAGE=local
'@ | Set-Content -LiteralPath $config -Encoding ascii
}
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-backend.ps1 -Port 5000
```

保持这个窗口运行。另开一个 PowerShell 窗口执行以下命令，分别看到 `ok` 和 `ready`。以后从同一目录启动，只需运行上面最后一行。

```powershell
Invoke-RestMethod 'http://127.0.0.1:5000/health'
Invoke-RestMethod 'http://127.0.0.1:5000/ready'
```

## 3. 让应用连接后端

登录页点「查看连接设置」。同一台电脑上的模拟器填 `http://10.0.2.2:5000`。同一可信局域网的真机填 `http://<后端电脑的局域网 IPv4>:5000`。点「应用此地址」，再点「检测后端连接」。检测通过后回到登录页，点「跳过登录，在线体验」。验证个人数据持久化时，再注册一个专用测试账号。

| 要体验的功能 | 操作 |
| --- | --- |
| 课程与作业导入 | 把 `演示测试数据/指导老师预演-20261028/02-课程与DDL/` 中的 `01_A_courses.csv` 和 `03_A_DDL.csv` 复制到设备下载目录，在「课程与作业」分别导入。应预览到 3 门课程、4 条作业。 |
| 学习记录和计划 | 在 App 查看导入记录与计划，用同一测试账号重新登录确认已保存。 |
| 知识库与练习 | 上传 `演示测试数据/指导老师预演-20261028/03-上传讲义/05_binary_tree_notes.txt`，观察处理状态。资料出题、图片识别和真实模型对话按 [02 后端部署](02-后端部署.md) 配置模型后验证。 |

SQLite 模式由 API 进程处理本地任务。需要独立知识库 worker 时，按 [02 后端部署](02-后端部署.md) 切换到自己的 PostgreSQL 演示库，再用 `start-all.ps1` 启动。完整验收步骤见 [04 功能验收与排障](04-功能验收与排障.md)。
