# 06 出题机制与 DDL 导入

## 1. 导入课程和作业

DDL 在 App 中指**作业截止日期**。用于建库的 PostgreSQL DDL 与迁移另见 [03 数据库与备份](03-数据库与备份.md)。

1. 完成 [04 功能验收与排障](04-功能验收与排障.md) 中的联机检查。为观察持久化，使用独立演示账号。
2. 从项目的 `演示测试数据/指导老师预演-20261028/02-课程与DDL/` 把 `01_A_courses.csv` 和 `03_A_DDL.csv` 复制到设备的下载目录。Excel 另存为 CSV 时选择 UTF-8 编码，日期列用 `YYYY-MM-DD`。
3. 在 App 的「课程与作业」切到课程，选择课程文件。预览确认数据结构、计算机网络、操作系统三门课及考试日期，再导入。
4. 切到作业，选择 DDL 文件。预览确认四条作业、关联课程、截止日期和时长。作业课程名与已导入课程保持一致。示例的固定日期可能已到期，要演示未来任务请复制样例并更新副本中的日期。
5. 回到今日计划或待办，检查导入记录。需要验收同步时，用同一演示账号登录第二台设备，刷新并核对。需要演示两个学习搭子，分别用 A、B 资料并建立两个独立账号。

课程 CSV 可沿用样例表头 `课程名称,考试日期,优先级,学习时长,状态`。作业 CSV 可沿用 `课程名称,作业标题,截止日期,优先级,预计时长`，预计时长按分钟填写。该目录另附同一批数据的 JSON 示例。课表图片识别需要可用的视觉模型，CSV 和 JSON 可用于复现文件导入。

## 2. 从大纲推荐到资料题

1. 按 [大纲推荐验收](../演示测试数据/大纲推荐验收/README.md) 使用同一课程下的两个 TXT。先上传「期末复习大纲」，等待知识库处理完成。
2. 进入「智能体 → 练习 → 专项练习」，选同一课程、保留「推荐」筛选，观察「大纲重点」。仅有大纲时，可从已配置的通用题源练习。
3. 上传同一课程的「二分法讲义」，等待处理完成，再选二分法。确认资料题源后开始练习，打开「查看原文依据」核对原文。
4. 提交作答，核对判分、解释、错题和复盘。评分以服务端规则和答案快照计算，模型用于理解输入、生成部分题目或解析。现场记录以页面实际显示的题源及模型状态为准。

讲义已处理但资料出题失败时，先检查课程归属、知识点和后端文本模型配置。拍题与课表图片识别还需视觉模型。离线演示可用内置题目复验流程。
