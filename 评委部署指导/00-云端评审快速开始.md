# 知学 Mate 云端评审快速开始

## 安装与使用

1. 解压提交 ZIP，取出 `hap/知学Mate-signed.hap`。当前安装包使用调试签名。请用已在签名 Profile 登记、系统 API 24 或以上的 HarmonyOS 手机或平板，或使用 API 24 的 DevEco Studio 模拟器。安装命令和 Wi-Fi 调试方式见 [安装 HAP](01-安装HAP与打开工程.md)。
2. 在设备桌面打开「知学 Mate」。评审包默认连接 `https://47.238.218.213`。如果是覆盖安装且设备保存过其他地址，在登录页点「查看连接设置」，填 `https://47.238.218.213`，再点「应用此地址」和「检测后端连接」。
3. 使用团队单独交接的评审账号登录，也可在登录页「注册」用测试手机号和密码创建独立账号。后端评审实例关闭了共享访客数据。在线验收请使用已登录账号。
4. 安装完成后，可以断开调试连接。切到手机移动数据后在浏览器打开 `https://47.238.218.213/ready`，看到 `{"status":"ready"}`，再从桌面打开 App，刷新课程或发一条学习问题。

## 功能验收

- 登录后，导入 `演示测试数据` 中的课程和作业样例，退出后重新登录，确认记录仍在。
- 在对话页询问「请用一句话解释二叉树的定义」，检查模型回复。
- 在「知识库」上传 TXT 讲义，等待解析完成后查看原文。可用包内 `05_binary_tree_notes.txt`。
- 华为账号登录、推送通知和跨设备能力请在相应的授权真机上验收。公共评审入口当前使用 HTTPS 公网 IP。

如果没有可用网络，可以从登录页点「离线演示（无需网络）」，体验应用内置的样例。需自建后端时，按 [现场独立部署](00-现场快速部署与体验.md) 操作。
