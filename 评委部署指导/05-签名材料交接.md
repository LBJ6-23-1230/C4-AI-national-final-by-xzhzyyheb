# 05 签名材料交接

## 评委收到的文件

用 `hap/知学Mate-signed.hap` 安装，按 `hap/manifest.json` 比对版本和 SHA-256。现包为 `com.zhixue.mate` 的 debug 包，兼容 API 24 及以上，调试 Profile 覆盖 14 台已登记设备。安装步骤见 [01 安装 HAP 与打开工程](01-安装HAP与打开工程.md)。

| 文件或参数 | 用途与保管 |
| --- | --- |
| `.hap` | 已签名的安装包，供授权评审设备安装。 |
| `.p7b` | 华为开发者中心签发的调试 Profile，绑定应用、调试证书、设备和有效期，由团队签名管理员保管。 |
| `.cer`（应用调试证书）和 `.p12` | `.cer` 供签名工具验证开发者证书链。`.p12` 含签名私钥，连同别名和密码由团队签名管理员保管。 |
| USB 测试 CA | 公开 CA 证书，仅用于团队在本机测试 HTTPS 转发。它与 HAP 签名证书分属两套配置。 |

调试 Profile 有效至北京时间 **2027-09-21 22:23:37**。评委换真机时先从 USB 连接并确认 `hdc list targets` 能看见设备，再由签名管理员通过 `hdc shell bm get --udid` 核对设备授权。多台设备时加 `-t '<连接标识>'`。请通过团队私密渠道交接 UDID。[华为注册调试设备说明](https://developer.huawei.com/consumer/cn/doc/app/agc-help-add-device-0000001946142249/)

## 团队管理员重新签名

1. 在 HarmonyOS 开发者中心的「开发者管理 → ID、证书和 Profile」登记评审设备。用 `com.zhixue.mate` 和配套的现用调试证书重新签发 Profile。
2. 从 DevEco Studio 打开 `app/`，在「File → Project Structure → Signing Configs」选择同一套调试证书、密钥库和新 Profile，填别名及密码，并给 `default` 产品绑定签名配置。使用团队已有的本地签名注入时，在工作区根的 `zhixue-signing/local-debug-signing.json` 中更新 Profile 路径即可。
3. 构建 `default / entry / debug`，用该 SDK 的签名工具运行 `verify-app` 核对 HAP，确认包名、版本和目标 Profile。把本次通过验签的 HAP 归档到 `hap/知学Mate-signed.hap`，重建 ZIP 和清单。
4. 在目标设备上安装并启动，验证登录页、离线体验和与该设备实际连接的后端。评委使用自己的签名重编时，华为账号、Push 等平台能力需要对应项目配置。

## 团队 USB HTTPS 专项联调

普通评审可使用 USB HTTP、可信局域网或标准 HTTPS，步骤见 [01 安装 HAP 与打开工程](01-安装HAP与打开工程.md)。

`app/entry/src/main/resources/rawfile/zhixue-usb-test-ca.cer` 是公开测试 CA，内容为 PEM 格式。当前开发构建仅在访问 `https://127.0.0.1:55001` 时使用它。CA 有效期截止北京时间 2027-11-11 21:44:51。演示和生产环境使用设备认可的 HTTPS 证书及真实域名。

1. 团队电脑启动隔离的测试后端，确认 `http://127.0.0.1:5000/ready` 返回 200。
2. 用团队管理的配套服务器证书和私钥启动本机 HTTPS 代理，监听电脑 `127.0.0.1:55001` 并转发到电脑 `127.0.0.1:5000`。叶证书由该测试 CA 签发，SAN 含 IP `127.0.0.1`。在电脑上确认 TLS 和代理上游都通过。

   ```powershell
   curl.exe --fail --cacert '.\app\entry\src\main\resources\rawfile\zhixue-usb-test-ca.cer' 'https://127.0.0.1:55001/ready'
   ```

Windows 的 curl 若使用 Schannel，且仅报测试 CA 无可用吊销服务器，可在上面命令中加入 `--ssl-revoke-best-effort`。证书链和 IP 仍要校验。

3. 用数据线连接已授权设备并解锁。保持代理运行，向设备建立 HDC 反向转发。单目标时可执行：

   ```powershell
   & $Hdc list targets
   & $Hdc rport tcp:55001 tcp:55001
   & $Hdc fport ls
   ```

4. 在 App 的「接口环境」手动填写 `https://127.0.0.1:55001`，应用地址，再检测连接。这个地址使用 App 内的受限 CA 配置。电脑命令用 `--cacert` 验证证书链。华为 OAuth 仍需由团队在后端配置 Client ID 与 Secret。
